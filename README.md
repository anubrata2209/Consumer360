## Consumer360 — Customer Segmentation & CLV Analytics

##  Project Overview


Consumer360 is a data analytics project focused on understanding how customers behave in an e-commerce business. The goal is to identify high-value customers, track purchasing patterns, and detect customers who might stop buying (churn).

 In this project, we built a complete end-to-end workflow using SQL, Python, and Power BI — starting from raw transaction data, cleaning and transforming it, analyzing customer behavior, and finally creating an interactive dashboard for insights.

---

##  Objectives
- Segment customers using RFM analysis
- Predict Customer Lifetime Value (CLV)
- Identify churn-risk customers
- Analyze revenue trends and product performance
- Discover product associations (Market Basket Analysis)

---

##   Tech Stack
- SQL (MySQL)
- Python (Pandas, Lifetimes, MLxtend)
- Power BI
- Excel
